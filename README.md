# 📬 Newsletter Subscription Component

This project is a responsive and modern newsletter subscription UI built using HTML and Tailwind CSS. It features a clean design, gradient header, and a user-friendly input form to encourage visitors to subscribe to a newsletter.

## ✨ Features

- Responsive layout using Flexbox and Tailwind CSS
- Eye-catching gradient banner
- User-friendly email input field
- Stylish "Subscribe Now" button
- Emphasis on user privacy
